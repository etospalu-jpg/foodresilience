# NADI Pangan — MVP PRD

## Product position

NADI Pangan is a Monitoring, Evaluation & Learning layer for food-vulnerability interventions. It does not replace FSVA, SKPG, food-price systems, or official source systems.

Core loop:

**Detect → Prioritize → Intervene → Verify → Measure → Learn → Adapt**

## MVP modules

1. Executive Overview
2. Intelligence Map
3. Region Profiles
4. Intervention Registry
5. Monitoring Workspace
6. Outcome & Evidence Readiness
7. Learning Repository
8. Attention Inbox / Rule Engine
9. Reports
10. Settings & data provenance

## UI principles

- Deep Forest `#123C32` as the restrained primary
- neutral surfaces and low visual noise
- desktop fixed/collapsible sidebar
- portrait-native bottom navigation
- no full-page horizontal overflow
- swipeable metric and filter strips on mobile
- subtle 160–260ms motion
- single premium outline icon family
- simulation data must be visibly labelled

## Data principles

- public pilot indicators preserve source period
- demo intervention records are simulation only
- no NIK, household identifiers, or personal health records in the MVP
- every important record is designed for provenance and verification
- rule engine surfaces review signals, not automated policy decisions

## Pilot regions

Banggai Kepulauan, Banggai Laut, Donggala, Sigi, and Palu.

## Acceptance baseline

The MVP is considered usable when a user can trace a region from vulnerability context through intervention, beneficiary coverage, monitoring status, outcome readiness, and institutional learning on both laptop and portrait screens.
